## 📌 Overview

Interactive Power BI dashboard analyzing 50,000+ retail transaction records. Designed for business intelligence with sales tracking, growth analysis, and inventory optimization.

## 🎯 Key Results

| Metric | Improvement |
|--------|-------------|
| **Stockout Reduction** | 15% |
| **Reporting Efficiency** | 70% faster |
| **Records Analyzed** | 50,000+ |
| **Dashboard Type** | Interactive with drill-down |

## 🛠️ Technologies

- **BI Tool:** Power BI
- **Data Modeling:** DAX, Power Query
- **Analysis:** Python (Pandas), Exploratory Data Analysis
- **KPIs Tracked:** Revenue, Growth %, Retention, Top Products

## 📊 Dashboard Features

1. **Sales Revenue** — Monthly/weekly/daily tracking
2. **Growth Analysis** — Month-over-month growth %
3. **Customer Retention** — Repeat purchase rates
4. **Top Products** — Best-selling items ranking
5. **Inventory Planning** — Stock level optimization
